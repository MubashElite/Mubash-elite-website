# Mubash Elite — Shopify Growth Consultancy Website

Source repository for the Mubash Elite website.

## Development

Install dependencies with `npm install`, then run `npm run dev`.

## Production build

Run `npm run build` to generate the static site in `dist/`.

The contact inquiry API currently uses AppDeploy backend services (`@appdeploy/sdk`). Deploying outside AppDeploy requires adapting that backend integration and configuring any required secrets.
